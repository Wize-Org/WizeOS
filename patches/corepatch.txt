Goal:
Implement WizeOS CorePatch so that, when persist.wizeos.corepatch is true, PackageManager allows:

1. Downgrade apps.
2. Install modified APKs over the same package name.
3. Install packages / split APKs with inconsistent signatures.

When persist.wizeos.corepatch is false or missing, Android must behave like stock.

    adb install -r -d older-version.apk

Problem / root cause:
Android rejects these installs because:

1. ParsingPackageUtils.getSigningDetails(...) collects APK signing details through ApkSignatureVerifier.verify(...).
2. ApkSignatureVerifier.verify(...) performs full APK content/signature verification.
3. ParsingPackageUtils rejects split APKs when Signature.areExactMatch(existingSigningDetails, verified.getResult()) is false, returning INSTALL_PARSE_FAILED_INCONSISTENT_CERTIFICATES.
4. InstallPackageHelper rejects replacement APKs when the new parsed signing details do not match the old installed signing details.
5. PackageManagerServiceUtils.verifySignatures(...) rejects existing package updates with INSTALL_FAILED_UPDATE_INCOMPATIBLE when signatures differ.
6. Downgrade checks reject older versionCode installs unless special stock conditions are satisfied.
7. KeySetManagerService and ReconcilePackageUtils can also reject updates before or after the normal signature checks.
